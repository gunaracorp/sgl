Token 03

Motion — Reveal + Stagger

Fade + slide-up 24px, 0.6s easeOut, sekali saat masuk viewport. Stagger antar kartu 0.08–0.15s. Kartu di section Kartu & Harga di atas sedang mendemokan ini — scroll naik-turun untuk melihat ulang. Wajib hormati prefers-reduced-motion.

Standar SEO

JSON-LD @graph — wajib tiap website

Template minimal. Bisnis cabang: tambah department per outlet dengan telephone, openingHoursSpecification & priceRange masing-masing (rujukan: json-ld.tsx di SGL).

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@graph": [{
    "@type": "DryCleaningOrLaundry",
    "name": "Samara Green Laundry",
    "url": "https://sgl.web.id",
    "telephone": "+628134506007",
    "priceRange": "Rp 1.000 - Rp 50.000",
    "openingHoursSpecification": [{ "dayOfWeek": ["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"], "opens": "07:00", "closes": "22:00" }],
    "memberOf": { "@type": "Organization", "name": "Asosiasi Laundry Digital Indonesia" }
  }, {
    "@type": "WebSite", "url": "https://sgl.web.id"
  }]
}
</script>
